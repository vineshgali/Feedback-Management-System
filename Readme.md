# Feedback Management System

## About the Project
The Feedback Management System is a full-stack web application that allows users to register, log in, and submit feedback. An admin dashboard allows submitted feedback to be viewed and managed.

## Features
- User registration and login
- Feedback submission
- View submitted feedback
- Admin dashboard to display feedback
- REST API integration between frontend and backend

## Technologies Used

**Backend**
- Java
- Spring Boot
- Spring Data JPA
- Maven

**Frontend**
- React.js
- JavaScript
- HTML
- CSS
- Axios

**Database**
- MySQL

**Tools**
- IntelliJ IDEA
- Git and GitHub
- Postman

## Project Structure

- `src/` – Java backend source code
- `pom.xml` – Maven dependencies and project configuration
- `mvnw` and `mvnw.cmd` – Maven wrapper scripts

## Getting Started

# Prerequisites
- Java JDK
- MySQL Server
- Node.js and npm
- IntelliJ IDEA or another suitable code editor

# Backend Setup
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Create a MySQL database for the application.
4. Configure the database URL, username, and password in your local Spring Boot configuration.
5. Run the Spring Boot application.

# Frontend Setup
Open the frontend project folder in a terminal and run:

```bash
npm install
npm run dev
```

# Testing
Use the frontend in your browser to register, log in, and submit feedback. You can also test the backend REST APIs using Postman.
